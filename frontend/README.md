# Sangyan Shield (संज्ञान शील्ड) 🛡️

> **Verify Before You Pay • धोखाधड़ी से पहले संज्ञान**
>
> India's Sovereign Civic AI Verification Shield against Deepfakes, UPI Fraud, Investment Scams, Voice Cloning, and Malicious URLs.

---

## 🌟 Overview

**Sangyan Shield** is a high-trust, authoritative civic fintech and cybersecurity platform engineered for digital India. It equips citizens, retail banking users, UPI adopters, and businesses with real-time AI-powered fraud verification before financial transactions take place.

---

## 🚀 Key Features

- **🛡️ 3D Interactive Defense Core:** Built with Three.js and `@react-three/fiber`, featuring ambient floating geometry, distorting mesh materials, and orbital security telemetry.
- **🔍 Multi-Modal Verification Workspace (`/verify`):**
  - **Screenshot / OCR Scanner:** Inspect WhatsApp forwards, Telegram tip channels, forged certificates, and payment slips.
  - **Link & Domain Inspector:** WHOIS age detection, SSL certificates, phishing detection, and malicious APK warning.
  - **SMS & Message Parser:** Flag suspicious urgency keywords, fake bank handles, and extortion templates.
  - **Voice & Deepfake Audio Analyzer:** Spectral voice cloning detection for synthetic audio impersonation.
- **🚨 1930 "Golden Hour" Emergency Reporting (`/report`):**
  - Instant one-click connection to the **1930 National Cyber Crime Helpline**.
  - Direct integration with the Ministry of Home Affairs portal (`cybercrime.gov.in`).
  - Structured incident intake generating an official **Police FIR Evidence Dossier** with SHA-256 fingerprinting.
- **📊 Real-Time Threat Analysis Simulator (`/analysis`):** Multi-stage telemetry pipeline displaying OCR extraction, entity attribution, SEBI database queries, and risk scoring.
- **📜 Audit History & Fraud Database (`/history`):** Public search and filterable directory of confirmed phishing domains, scam UPI VPAs, and blacklisted numbers.
- **🎓 Civic Micro-Lessons (`/learn`):** Interactive byte-sized modules covering UPI safety, digital arrest scams, task frauds, and QR code hygiene.

---

## 🛠️ Technology Stack

- **Framework:** React 19 (Hooks, Context, Suspense, Lazy Loading)
- **Build Tool:** Vite 8 with `@vitejs/plugin-react`
- **3D Graphics:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations:** Framer Motion (Page transitions, micro-interactions, modal orchestration)
- **Icons:** Lucide React
- **Styling:** Custom CSS Design System with 8pt grid, WCAG-compliant deterministic risk tokens, and bilingual typography (**Inter** & **Noto Sans Devanagari**)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/anjali-0404/Sangyaan.git

# Navigate into the project directory
cd Sangyaan

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
